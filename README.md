Terminal Hacker Toolkit

A modular Python CLI for reverse engineering, binary analysis, cryptography, and executable inspection.

Status: In Development

Installation

Clone the repository:

```
git clone https://github.com/iamthehunter1/terminal-hacker-toolkit.git
cd terminal-hacker-toolkit 

```

Install dependencies:
```
python -m pip install -r requirements.txt
```
Usage

Run the toolkit:
```
python main.py
```
Development

This project is actively under development. Features and documentation will be updated as development progresses.
